# Reporter (guide step 7)

**Owners:** Varsha, with Keerthana for the numbers.

Turns the run folder into a report that answers: which tasks can move to open models,
what would that save, and what was not measured. Shows strict and wording-ignored scores
side by side. Start now, using the files in `examples/`.

Done when:
- [ ] fed the xarray results, the summary matches the run report's numbers
- [ ] strict and wording-ignored scores always appear together
- [ ] someone outside the project can state the recommendation in one sentence
