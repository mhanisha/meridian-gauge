# Task checklist (task E2)

A candidate is usable only if every answer is yes. Record the reason for any no.

- [ ] It changed at least one test file.
- [ ] Its tests need no database, web server or internet.
- [ ] The change is self-contained (not several unrelated changes squashed together).
- [ ] A description exists that says what to change, not only a title.
- [ ] The description can be given without revealing the tests or the solution.
